How publishing works

This site is fully static — there is no server or database. Your edits are stored in this browser, so you see them immediately on the live site from this device, but other visitors still get the shipped content.

  1. Make your changes in this console.
  2. Click Download data.js below.
  3. Replace data.js in your project with the downloaded file and deploy.

Everyone then sees your content, because it becomes the new shipped default.
